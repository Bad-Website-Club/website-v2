## Instructor notes

### [Working with CSS Variables: What Are CSS Custom Properties, and How Do They Work?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-variables/what-are-css-custom-properties)

With CSS variables (or, custom properties), we can reuse values.

To declare a variable, the property name has to start with two dashes (`--`). Usually, global variables are declared inside the `:root`, because it represents the highest-level parent in the DOM tree.

We can use the variable on an element using the `var()` function:

```css
:root {
  --bwc-purple: #ba6dc6;
}

.container {
  border: 2px solid var(--bwc-purple);
}
```

Since they follow the CSS cascade, we can redefine them on a specific element:

```css
:root {
  --main-color: #3498db;
}

.button {
  background-color: var(--main-color);
}
```

Using variables is common when designing dark/light themes...:

```css
:root {
  --bg-color: black;
}

body {
  background-color: var(--bg-color);
}

.light-theme {
  --bg-color: white;
  --text-color: black;
  background-color: var(--bg-color);
  color: var(--text-color);
}
```

...and with media queries to create responsive designs:

```css
:root {
  --card-width: 90%;
  --card-bg: #f0f0f0;
  --card-padding: 1rem;
  --text-color: #333;
}

/* Tablet screens and up */
@media (min-width: 600px) {
  :root {
    --card-width: 70%;
    --card-bg: #e8f5e9;
    --card-padding: 1.5rem;
  }
}

/* Desktop screens and up */
@media (min-width: 1024px) {
  :root {
    --card-width: 50%;
    --card-bg: #d0f0ff;
    --card-padding: 2rem;
  }
}
```

We can also add a fallback value inside the `var()` function.

In this example, if `--text-color` is not defined, it will default to `green`:

```css
:root {
  --text-color: green;
}

.text {
  color: var(--text-color, green);
}
```

Variables can reference other variables as well:

```css
:root {
  --primary-color: #3498db;
  --button-bg: var(--primary-color);
}

button {
  background-color: var(--button-bg);
}
```

While variables are well-supported, there might be some older browsers that may not recognize them, so we should make sure to provide fallback values.

### [Working with CSS Variables: What Is the @property Rule, and How Does It Work with Fallbacks?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-variables/what-is-the-at-property-rule)

With `@property` rule, variables (or, custom properties) can be explicitly defined.

```css
@property --main-color {
  syntax: '<color>';
  inherits: false;
  initial-value: #3498db;
}

.button {
  background-color: var(--main-color);
}
```

- `syntax` is the type of the property, for example, it can be `<color>`, `<length>`, `<number>`, `<percentage>`, or more complex types.
- `inherits` specifies whether the property should inherit its value from its parent element.
- `initial-value` is the default value of the property.

With `@property`, custom properties can even be animated!

In this example, when the `div` is hovered over, the gradient angle will smoothly change to 90 degrees:

```html
<div class="gradient-box"></div>
```

```css
@property --gradient-angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

.gradient-box {
  width: 100px;
  height: 100px;
  background: linear-gradient(var(--gradient-angle), red, blue);
  transition: --gradient-angle 0.5s;
}

.gradient-box:hover {
  --gradient-angle: 90deg;
}
```

To provide fallbacks to variables defined with `@property`, we can consider:

- Declaring the variable in traditional way alongside the `@property` rule:

```css
:root {
  --main-color: #3498db;
}

@property --main-color {
  syntax: '<color>';
  inherits: false;
  initial-value: #3498db;
}

body {
  background-color: var(--main-color);
}
```

- Using a fallback value inside `var()`:

```css
@property --main-color {
  syntax: '<color>';
  inherits: false;
  initial-value: #3498db;
}

body {
  background-color: var(--main-color, #3498db);
}
```

- Providing type-safe fallbacks in `initial-value` (making sure the `initial-value` reflects the type defined in `syntax`):

```css
@property --padding {
  syntax: '<length>';
  inherits: false;
  initial-value: 10px;
}

.box {
  width: 100px;
  height: 100px;
  background-color: darkred;
  color: white;
  padding: var(--padding);
}
```
