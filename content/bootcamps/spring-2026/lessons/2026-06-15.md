### [Working with CSS Fonts: What Are the Fundamentals of Typography?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-are-the-fundamentals-of-typography)

A typeface is similar to a blueprint for a family of fonts. It's the _overall design and style of a set of characters, numbers, and symbols_. It helps us communicate effectively.

A font is a specific variation of a typeface with its own size, width, style, etc.

Serif and Sans Serif are examples of typefaces.

Serif typefaces are more classical and have small lines at the end of characters. Some examples are:
- Times New Roman
- Georgia
- Garamond

Sans Serif is more "modern" without the small lines at the end of characters. Some examples are:
- Helvetica
- Arial
- Roboto

There are other typefaces such as Script, Blackletter, Monospaced, and Decorative.

Like typefaces, fonts can also be grouped based on the weight (the thickness of the characters), style (the slant and orientation of the characters), and width (the horizontal space occupied by characters).
For example, Times New Roman has Times New Roman Bold, Times New Roman Italic, and Times New Roman Bold Italic.

Some fundamental elements of typography are:
- **Baseline** (the imaginary line on which most characters rest)
- **Cap height** (the height of the uppercase letters, measured from baseline to the top)
- **x-height** (the average height of lowercase letters, excluding ascenders and descenders)
- **Ascenders** (the parts of lowercase letters that extend above the x-height, for example, the tops of letters `h`, `b`, `d`, and `f`)
- **Descenders** (the parts of lowercase letters that extend below the baseline, for example, the tails of letters `y`, `g`, `p`, and `q`)

Some other important concepts are:
- **Kerning** (how space is adjusted between specific pairs of characters)
- **Tracking** (how space is adjusted between all characters in a block of text; the distance between the characters)
- **Leading** (the vertical space between lines of text, measured from the baseline of one line to the baseline of the next line)

### [Working with CSS Fonts: What Are Some Best Practices for Working with Typography in Your Designs?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-are-some-best-practices-for-working-with-typography-in-your-designs)

We should be mindful of using best practices when working with typography. Some of these best practices are:
- Choosing clear fonts to make designs easy to understand
- Using large enough text and keeping lines relatively short
- Using font-size to create a visual hierarchy for elements
- Using at most two or three fonts to maintain consistency
- Using whitespace effectively to create visual balance
- Following the Web Content Accessibility Guidelines, especially using the recommended contrast ratio for text
- Providing options to adjust font size
- Making sure that the fonts are displayed correctly on different screen sizes

### [Working with CSS Fonts: What Are Font Families and How Do They Work?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-are-font-families)

A font family is a group of fonts that are based on the same typeface but have different weights, styles, and widths. For example, Arial is a font family that includes variations like Arial Bold and Arial Italic.

We can set the font family in CSS with the `font-family` property. We can specify multiple font families by separating them with commas. If the first font family is not found or can't be loaded, the others will act as fallback options one after another.

For example, here if Arial is not found, Lato will be tried:

```css
p {
  font-family: Arial, Lato;
}
```

If a font lacks a specific character, the browser will look at the second (or other) fonts specified.

If none of the specified fonts are found or can be loaded, the browsers render a generic font family, which is the default font.
Common generic fonts are `serif`, `sans-serif`, `monospace`, `cursive`, and `fantasy`.

That's why it's also important to provide a generic fallback font when defining `font-family`:

```css
p {
  font-family: Arial, Lato, sans-serif;
}
```

### [Working with CSS Fonts: What Are Web Safe Fonts?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-are-web-safe-fonts)

Web-safe fonts are fonts that are more likely to be installed on a computer or a device. We should use web-safe fonts to make sure the fallback font is still consistent with the first priority font. Using web-safe fonts also reduces the load time, since they don't need to be downloaded if they're already installed.

Some of the web-safe sans-serif fonts are Arial, Verdana, and Trebuchet MS.

Some of the web-safe serif fonts are Times New Roman and Georgia.

### [Working with CSS Fonts: What Is the @font-face At-Rule, and How Does It Work?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-is-the-font-face-at-rule)

CSS at-rules provide instructions to the browser. `@font-face` is an at-rule that we can use to define a custom font, specifying the font file, format, and other properties.

The `font-family` descriptor is the name of the font, `src` descriptor is the list of external references or locally installed font faces defined with the `url` function. For each font resource, we can also specify the `format`. If `format` is omitted, the format of the font will be detected after it's downloaded.

Some common formats are:
- `woff`
- `woff2`
- `svg`
- `truetype`
- `opentype`
- `collection`
- `embedded-opentype`

For example:

```css
@font-face {
  font-family: "MyCustomFont";
  src: url("path/to/font.woff2") format("woff2"),
    url("path/to/font.otf") format("opentype"),
    url("path/to/font.woff") format("woff");
}
```

Optionally, the technology of the font resource can also be specified:

```css
@font-face {
  font-family: "MyCustomFont";
  src: url("path/to/font.woff2") format("woff2"),
    url("path/to/font.otf") format("opentype") tech(color-COLRv1),
    url("path/to/font.woff") format("woff");
}
```

Then, we can use the custom font elsewhere in our CSS:

```css
body {
  font-family: "MyCustomFont";
}
```

### [Working with CSS Fonts: How Do You Work with External Fonts Like Font Squirrel and Google Fonts?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/how-do-you-work-with-external-fonts-like-font-squirrel-and-google-fonts)

External fonts are fonts that are not included locally but rather hosted on an external server. Some online resources for using free fonts are:
- [Google Fonts](https://fonts.google.com)
- [Font Squirrel](https://www.fontsquirrel.com)

(_Another open-source, privacy-first web font platform is [Bunny Fonts](https://fonts.bunny.net), which doesn't track personal data and can be used as a replacement for Google Fonts!_)

We can see the details and information about a font on these sites.

In Google Fonts, once the "Get font" button is clicked, there are options to "Download all" or "Get embed code." If we use the embed code option, the font can be used as an external font on Google's servers. With that option, we can use a `link` element or `@import`. With `link`, we can add it inside the project's `head` HTML element. With `@import`, we can add that rule to our CSS file.

In Font Squirrel, once we've chosen a font, we can go to the "Webfont Kit" tab and check if the font's license allows us to use it in `@font-face`. If so, clicking the "Download @font-face Kit" button will download a zip file. Once it's unzipped, the "web fonts" folder includes an HTML file with instructions on how to use web fonts.

Note that using multiple external fonts can increase the load time of the website and affect its overall performance.

### [Working with CSS Fonts: What Is the text-shadow Property, and How Does It Work?](https://www.freecodecamp.org/learn/responsive-web-design-v9/lecture-working-with-css-fonts/what-is-the-text-shadow-property)

We can add shadows to text with the `text-shadow` property, giving it the values for the `X` offset, `Y` offset, color and blur radius.

Positive values move the shadow right (`X` offset) and down (`Y` offset).
Negative values move the shadow left (`X` offset) and up (`Y` offset).

Color can be defined before or after the `X` and `Y` offsets and blur radius.

Blur radius has the default value of `0`. If the value is higher, the blur will be bigger (that is, the shadow becomes lighter).

```css
p {
  text-shadow: 3px 2px 3px #00ffc3;
}
```

We can also define multiple text shadows:

```css
p {
  text-shadow:
    3px 2px 3px #00ffc3,
    -3px -2px 3px #0077ff,
    5px 4px 3px #dee7e5;
}
```
